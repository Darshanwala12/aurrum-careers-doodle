# Original AI Career Counsellor 3D Character Pack

This pack contains four newly generated, original, lightweight stylized 3D career-counsellor avatars for web prototypes.

## Characters
- Aria — ponytail, navy trouser suit
- Elena — bob hairstyle, navy skirt suit
- Priya — bun hairstyle, navy trouser suit
- Sophie — bun hairstyle, navy skirt suit

## Formats included
Each character includes `.glb`, `.gltf`, and `.bin` files.

## Animation clips
`idle`, `thinking`, `talking`, `greeting`, `explaining`, `pointing`, `encouraging`, `happy`, `surprised`, `success`

## Notes
These are original procedural web-ready starter characters. They are not copies of the uploaded reference model. They use articulated node hierarchies and named animation clips. They do not yet contain a formal VRM humanoid meta-rig, finger bones, or phoneme blendshapes.

For production lip-sync, add facial blendshapes/visemes in Blender or another DCC tool and export GLB or VRM.
